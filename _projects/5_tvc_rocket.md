This project focuses on thrust vector control (TVC) for rocket attitude stabilization and trajectory tracking.

I designed the TVC control system, developed software-in-the-loop simulation for algorithm verification, and conducted flight tests to evaluate the control performance. The current work also investigates optimal trajectory planning for rocket ascent and recovery.
